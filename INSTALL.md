# Установка бота «Обед в столовой» на Windows-сервер

Руководство для системного администратора. Время установки — 20–30 минут.

## 1. Что это за программа

| | |
|---|---|
| Язык | Python 3.11+ (библиотеки: aiogram, APScheduler, openpyxl) |
| База данных | SQLite — один файл `lunch.db` в папке бота, отдельный сервер БД не нужен |
| Сеть | только **исходящий HTTPS (443) на `api.telegram.org`**. Входящие порты, белый IP и домен **не нужны** — бот сам опрашивает Telegram (long polling) |
| Ресурсы | ~60 МБ ОЗУ, ~150 МБ на диске, нагрузка на CPU около нуля |
| Процесс | один постоянно работающий процесс `python bot.py` |

**Важно:** один токен — один запущенный экземпляр. Если запустить бота второй раз (на другом ПК или вторым окном),
Telegram будет выдавать ошибку `Conflict: terminated by other getUpdates request`.

## 2. Что получить у владельца бота

1. **Токен бота**: строка вида `7123456789:AAH...`. Это пароль от бота, не публикуйте его.
2. **Доступ к коду**: репозиторий `github.com/Zayn1ddinov/lunch-bot` приватный. Один из вариантов:
   - владелец добавляет ваш GitHub-аккаунт: *Settings → Collaborators → Add people*;
   - или присылает ZIP-архив репозитория (*Code → Download ZIP*).
3. Владелец бота в @BotFather должен выполнить `/setprivacy` → выбрать бота → **Disable**.
   Без этого бот не видит сообщения «+» в группе.

## 3. Установка

### 3.1. Python
1. Скачайте Python 3.12 с https://www.python.org/downloads/windows/ (Windows installer 64-bit).
2. При установке отметьте **Add python.exe to PATH**.
3. Проверка в новом окне cmd:
   ```
   python --version
   ```
   Должно быть `Python 3.11` или новее.

### 3.2. Код бота
С git (так проще обновлять):
```
git clone https://github.com/Zayn1ddinov/lunch-bot.git C:\bots\lunch-bot
```
Без git распакуйте ZIP в `C:\bots\lunch-bot`. Внутри должны лежать `bot.py`, `start.bat` и другие файлы, а не ещё одна вложенная папка.

### 3.3. Файл настроек `.env`
Создайте файл `C:\bots\lunch-bot\.env` (имя начинается с точки, без `.txt`).
В Блокноте: *Сохранить как → Тип файла: Все файлы → Имя: `.env` → Кодировка: UTF-8*.

```
BOT_TOKEN=сюда_токен
GROUP_CHAT_ID=
KITCHEN_CHAT_ID=
ADMIN_IDS=
TIMEZONE=Asia/Tashkent
```

ID групп пока оставьте пустыми, они заполняются в шаге 5.

## 4. Первый запуск

Дважды щёлкните `C:\bots\lunch-bot\start.bat`.

- При первом запуске создаётся виртуальное окружение `venv` и ставятся зависимости (1–3 минуты, нужен интернет).
- Нормальный запуск выглядит так:
  ```
  ... WARNING GROUP_CHAT_ID / KITCHEN_CHAT_ID не заданы — опросы не запускаются ...
  ... INFO Start polling
  ... INFO Run polling for bot @имя_бота ...
  ```
  Предупреждение про `GROUP_CHAT_ID` на этом шаге — норма.

Окно пока не закрывайте.

## 5. Узнать ID групп и администраторов

Это делает владелец бота или администратор группы в Telegram:

1. Добавить бота в **группу сотрудников** и назначить его **администратором** (право закреплять сообщения).
   Написать в группе `/chatid`. Число из ответа (вида `-100…`) записать в `GROUP_CHAT_ID`.
2. Добавить бота в **группу кухни** и написать там `/chatid`. Число записать в `KITCHEN_CHAT_ID`.
3. Написать боту **в личку** `/chatid`. «ваш user_id» записать в `ADMIN_IDS`. Несколько ID указываются через запятую.
   Администраторы группы сотрудников получают доступ к панели автоматически, перечислять их не обязательно.

Итоговый `.env`:
```
BOT_TOKEN=7123456789:AAH...
GROUP_CHAT_ID=-1001234567890
KITCHEN_CHAT_ID=-1009876543210
ADMIN_IDS=123456789
TIMEZONE=Asia/Tashkent
```

Закройте окно `start.bat` и запустите его снова. Предупреждения про `GROUP_CHAT_ID` больше быть не должно.

## 6. Автозапуск

Перед настройкой автозапуска **закройте окно `start.bat`**, иначе будет два экземпляра.
Выберите один из вариантов. Если другие боты на сервере уже запускаются каким-то способом, используйте тот же.

### Вариант А. Служба Windows через NSSM (рекомендуется)
1. Скачайте NSSM: https://nssm.cc/download и распакуйте `nssm.exe` (win64), например в `C:\tools\`.
2. В cmd **от имени администратора**:
   ```
   C:\tools\nssm.exe install LunchBot C:\bots\lunch-bot\venv\Scripts\python.exe bot.py
   C:\tools\nssm.exe set LunchBot AppDirectory C:\bots\lunch-bot
   C:\tools\nssm.exe set LunchBot DisplayName "Telegram бот: обеды"
   C:\tools\nssm.exe set LunchBot Start SERVICE_AUTO_START
   C:\tools\nssm.exe set LunchBot AppExit Default Restart
   C:\tools\nssm.exe set LunchBot AppRestartDelay 10000
   C:\tools\nssm.exe start LunchBot
   ```
3. Управление: `nssm start|stop|restart LunchBot` или оснастка `services.msc`.

Папка `venv` к этому моменту уже должна существовать: её создаёт первый запуск `start.bat` в шаге 4.

### Вариант Б. Планировщик заданий
1. *Планировщик заданий → Создать задачу* (именно «Создать задачу», не «простую»).
2. **Общие:** имя `LunchBot`, «Выполнять для всех пользователей» / «Выполнять вне зависимости от регистрации пользователя».
3. **Триггеры:** «При запуске».
4. **Действия:** программа `C:\bots\lunch-bot\start.bat`, рабочая папка `C:\bots\lunch-bot`.
5. **Параметры:** **снимите** галочку «Останавливать задачу, выполняемую дольше: 3 дн.».
   Иначе бот будет отключаться каждые 3 дня. При сбое `start.bat` сам перезапускает бота через 10 секунд.
6. Запустите задачу вручную (ПКМ → Выполнить) и проверьте лог.

## 7. Проверка после запуска

1. В личке с ботом: `/admin`. Должна открыться панель.
2. В панели: **▶️ Открыть опрос**. В группе сотрудников появится опрос.
3. Проголосуйте **«Буду обедать»**, затем в панели нажмите **📤 Отправить на кухню**. Заявка придёт в группу кухни.
4. Каждый администратор должен один раз нажать **Start** у бота в личке.
   Иначе бот не сможет присылать ему скриншоты оплат: это ограничение Telegram.

Дальнейшие настройки (время, цена, карта, меню) делаются в `/admin`, перезапуск для них не нужен.

## 8. Логи

- Файл `C:\bots\lunch-bot\logs\bot.log`: последние ~25 МБ, 5 файлов по 5 МБ с ротацией.
- Строки вида `Update id=… is handled` — это нормальная работа.
- В рабочие дни в логе видно `Опрос на … опубликован` и `Отчёт на … отправлен`.

## 9. Резервное копирование (обязательно)

В `lunch.db` хранятся все обеды, оплаты и долги сотрудников. Без копии при сбое диска данные о деньгах будут потеряны.

- Копия вручную: запустите `backup.bat`. Копия появится в `backups\lunch_ГГГГ-ММ-ДД.db`, хранятся последние 30.
  Копию можно делать при работающем боте.
- Ежедневно: в Планировщике создайте задачу «Ежедневно, 23:00» → программа `C:\bots\lunch-bot\backup.bat`,
  рабочая папка `C:\bots\lunch-bot`.
  Чтобы копии сохранялись на другой диск или в сетевую папку, укажите её в «Аргументах»: `D:\Backups\lunch-bot`.
- Восстановление: остановить бота, заменить `lunch.db` нужной копией (переименовав её в `lunch.db`), запустить бота.

## 10. Обновление бота

```
nssm stop LunchBot                         (или остановить задачу в Планировщике)
cd C:\bots\lunch-bot
git pull
venv\Scripts\pip install -r requirements.txt
nssm start LunchBot
```
Без git: распакуйте новый ZIP поверх папки, **не удаляя** `.env`, `lunch.db`, `venv`, `logs`, `backups`.

## 11. Перенос на другой сервер

Остановите бота на старом сервере. На новом установите всё по этой инструкции и скопируйте туда `.env` и `lunch.db`.

## 12. Если что-то не работает

| Признак | Причина и решение |
|---|---|
| `'python' не является внутренней или внешней командой` | Python не добавлен в PATH: переустановите с галочкой *Add to PATH* и откройте новое окно cmd |
| `KeyError: 'BOT_TOKEN'` | Нет файла `.env` или он называется `.env.txt`. Включите в Проводнике показ расширений и проверьте имя |
| `Unauthorized` / `Not Found` при запуске | Неверный токен: скопируйте его заново из @BotFather, без пробелов |
| `Conflict: terminated by other getUpdates request` | Бот запущен дважды: проверьте другие окна, службу, задачу Планировщика и другой ПК |
| `Cannot connect to host api.telegram.org` | Нет доступа в интернет или его блокирует фаервол/прокси. Нужен исходящий HTTPS на `api.telegram.org:443` |
| Бот не реагирует на «+» в группе | Не выключен privacy mode: @BotFather → `/setprivacy` → Disable, затем удалить бота из группы и добавить снова |
| Опрос не закрепляется | Бот не администратор группы |
| Админу не приходят скриншоты оплат | Админ не нажимал Start у бота в личке |
| Опрос приходит не в то время | Проверьте `TIMEZONE` в `.env` и время в `/admin` → Настройки |
| `ModuleNotFoundError` после обновления | Выполните `venv\Scripts\pip install -r requirements.txt` |
| Сломалось виртуальное окружение | Удалите папку `venv` и запустите `start.bat`, он создаст её заново |

## Файлы в папке бота

| Файл/папка | Что это | Можно удалять? |
|---|---|---|
| `.env` | токен и ID групп | нет |
| `lunch.db` | **все данные** | нет, делайте копии |
| `venv\` | библиотеки Python | да, `start.bat` создаст её заново |
| `logs\` | логи | да |
| `backups\` | резервные копии | старые — да |
| `*.py`, `*.bat`, `requirements.txt` | код | обновляются через `git pull` |
