# Бот «Обед в столовой»

Собирает заявки на обед в группе офиса, отправляет их на кухню, ведёт учёт обедов и оплат.

## Для сотрудников
- В группе каждый рабочий день появляется **опрос Telegram** «Будете обедать?» (варианты: буду / буду + гость / не буду). Можно и просто написать `+`, `+2`, `-` в чат.
- В личке с ботом **/start**:
  - при первом запуске бот спрашивает **официальные имя и фамилию** — по ним ведётся учёт (если пропустить — берётся имя из Telegram);
  - показывает **долг**, даты обедов за месяц, историю оплат, меню на неделю.
- **Оплата** (/pay или кнопка «💳 Оплатить»): бот показывает долг и номер карты → сотрудник пишет сумму → присылает скриншот. Админ получает фото с кнопками «Подтвердить / Отклонить». Долг уменьшается после подтверждения.
- Раз в неделю должникам приходит **напоминание об оплате** с номером карты.

## Для администраторов — /admin в личке с ботом
Доступ: администраторы группы сотрудников и ID из `ADMIN_IDS`.

- 📊 кто записался сегодня, ▶️ открыть опрос, 📤 отправить заявку на кухню досрочно, ⏭ пропустить / ❌ отменить день, ⏸ пауза;
- 👥 **Сотрудники**: изменить официальные имя и фамилию, 💵 внести оплату наличными (или корректировку со знаком минус);
- 💰 **Долги**: список должников, 📣 напомнить сейчас;
- 💳 **Оплаты на проверке**: скриншоты, которые ещё не подтверждены;
- 🍲 **Меню на неделю**: заполнить по дням, скопировать с прошлой недели. Меню показывается в опросе. В последний рабочий день недели в 15:00 бот напоминает админам, если меню на следующую неделю не заполнено;
- 📈 **Отчёты и Excel** за месяц/период. Листы: Итоги, Табель, По дням, Оплаты, Долги;
- ⚙️ **Настройки**: время опроса/напоминания/закрытия, дни недели, способ голосования (опрос Telegram или плюсики), цена обеда, номер карты, день и время напоминания должникам.

Цена фиксируется на каждый день: если поменять цену, прошлые обеды не пересчитываются.

## Установка на сервер
Подробное руководство для системного администратора: [INSTALL.md](INSTALL.md).

## Настройка (кратко)
1. @BotFather → `/newbot` → получите токен. Там же `/setprivacy` → бот → **Disable** (чтобы бот видел «+» в группе).
2. Создайте `.env` по образцу `.env.example`, впишите токен.
3. Запустите бота, добавьте его в группу сотрудников **администратором**, напишите там `/chatid` → `GROUP_CHAT_ID`.
4. Добавьте бота в группу кухни, `/chatid` → `KITCHEN_CHAT_ID`. Себе в личку `/chatid` → `ADMIN_IDS`.
5. Перезапустите бота. Всё остальное настраивается в `/admin`.

Админам нужно один раз нажать Start у бота в личке — иначе Telegram не даст боту присылать им скриншоты оплат.

## Запуск на Windows
1. Python 3.11+ с python.org (галочка **Add Python to PATH**).
2. Папка бота, например `C:\bots\lunch-bot`, в ней файл `.env`.
3. Запустите `start.bat` — при первом запуске установит зависимости; если бот упадёт, перезапустит через 10 секунд.
4. Автозапуск: Планировщик заданий → «Создать задачу» → триггер «При запуске компьютера» → действие `C:\bots\lunch-bot\start.bat`, рабочая папка `C:\bots\lunch-bot`, «Выполнять вне зависимости от регистрации пользователя».

Обновление: `git pull` в папке бота и перезапуск. Файлы `.env` и `lunch.db` (вся статистика и оплаты) не трогайте — делайте копию `lunch.db` время от времени.

Один токен — один запущенный бот: если запустить второй экземпляр, Telegram выдаст `Conflict: terminated by other getUpdates request`.
