# Бот «Обед в столовой»

Работает в общей группе офиса: собирает «+» на обед, отправляет заявку на кухню и ведёт статистику.

## Как это работает
1. В `POLL_TIME` (09:00, пн–пт) бот пишет в группу «Кто будет обедать — поставьте +» и закрепляет сообщение.
2. Сотрудники пишут в группу:
   - `+` — буду обедать;
   - `+2` — с гостем (2 порции);
   - `-` — передумал.
   Бот ставит 👍 на сообщение и обновляет список в закреплённом сообщении. Повторный «+» не считается дважды.
3. В `REMIND_TIME` (10:15) напоминает в группе.
4. В `REPORT_TIME` (10:45) закрывает приём и отправляет на кухню число порций и список имён.

## Панель администратора
Админ пишет боту **в личку** `/admin`. Доступ есть у администраторов группы сотрудников и у тех, кто указан в `ADMIN_IDS`.

В панели можно:
- 📊 посмотреть, кто записался сегодня;
- 📈 открыть отчёт за этот или прошлый месяц либо за любой период и **📥 скачать Excel**
  (листы «Итоги» — дни, порции и сумма по каждому; «Табель» — сотрудники × дни; «По дням»);
- 🕘 ⏰ 🔒 поменять время опроса, напоминания и закрытия (применяется сразу, без перезапуска);
- 📅 выбрать дни недели;
- 💰 задать цену обеда, чтобы считались суммы;
- ▶️ открыть опрос вручную, 📤 отправить заявку на кухню досрочно;
- ⏭ пропустить сегодняшний день (праздник), ❌ отменить уже открытый опрос, ⏸ поставить опросы на паузу.

## Статистика
- `/stats` — кто сколько дней обедал в текущем месяце;
- отчёт за другие периоды и Excel — в панели `/admin`.

## Настройка
1. Создайте бота у @BotFather и получите токен.
2. **Обязательно:** в @BotFather → `/setprivacy` → выберите бота → **Disable**. Без этого бот не видит обычные сообщения «+» в группе. (Если бот уже в группе — удалите и добавьте заново.)
3. Добавьте бота в группу сотрудников и сделайте админом (чтобы закреплял сообщение). Напишите там `/chatid` → это `GROUP_CHAT_ID`.
4. Добавьте бота в группу кухни, напишите `/chatid` → `KITCHEN_CHAT_ID`.
5. Напишите боту в личку `/chatid` → ваш ID в `ADMIN_IDS`.
6. `cp .env.example .env`, заполните.

## Запуск на Windows (офисный сервер)
1. Установите Python 3.11+ с python.org (галочка **Add Python to PATH**).
2. Скопируйте папку бота, например в `C:\bots\lunch_bot`.
3. Создайте в ней файл `.env` по образцу `.env.example`.
4. Запустите `start.bat`. При первом запуске он сам установит зависимости. Если бот упадёт, батник перезапустит его через 10 секунд.
5. Автозапуск после перезагрузки: Планировщик заданий → «Создать задачу» → триггер «При запуске компьютера» →
   действие «Запуск программы» `C:\bots\lunch_bot\start.bat`, «Рабочая папка» — `C:\bots\lunch_bot`,
   «Выполнять вне зависимости от регистрации пользователя». Либо так же, как запущены ваши другие боты.

Важно: один токен — один запущенный бот. Перед запуском в офисе остановите тестовую версию на Railway,
иначе Telegram выдаст ошибку `Conflict: terminated by other getUpdates request`.
Чтобы перенести накопленную статистику, скопируйте файл `lunch.db`.
